## 🧪 Featured projects

### 🐚 [Grok CLI](https://github.com/abhayKashyap03/grok-cli)

**Grok, at home in your terminal.** A Rust coding agent that reads, edits, and tests code, with streaming sessions, resumable conversations, MCP tools, and diff approvals. The interesting bits: permission boundaries, hooks, and restricted subagents.

![Rust](https://img.shields.io/badge/Rust-895E50?style=flat&logo=rust&logoColor=white) ![MCP](https://img.shields.io/badge/MCP-68649A?style=flat)

### 🧵 [Computer-Use Runtime](https://github.com/abhayKashyap03/computer-use-runtime)

**Teach a workflow once; replay it without the model.** Turns model-discovered browser workflows into typed, versioned capabilities. Replay checks policy and postconditions, and hands control back to a person in the same browser session when needed.

![TypeScript](https://img.shields.io/badge/TypeScript-497B98?style=flat&logo=typescript&logoColor=white) ![Playwright](https://img.shields.io/badge/Playwright-5B816C?style=flat)

### 🥗 [AI Health & Fitness Coach](https://github.com/abhayKashyap03/fitness-ai)

**The code does the math. The coach explains it.** Brings recovery, nutrition, weight, and training data into a local SQLite store. Deterministic calculations and explicit source precedence support the AI's advice, with a dashboard and grounding evaluations to check it.

![Python](https://img.shields.io/badge/Python-587D91?style=flat&logo=python&logoColor=white) ![SQLite](https://img.shields.io/badge/SQLite-6D768E?style=flat&logo=sqlite&logoColor=white)

### 🗣️ [Call Assistant](https://github.com/abhayKashyap03/call_assistant)

**A knowledge base that can pick up the phone.** A Gemini-powered voice assistant connecting Twilio calls to retrieval, with a Flask service and React interface.

![Python](https://img.shields.io/badge/Python-587D91?style=flat&logo=python&logoColor=white) ![Flask](https://img.shields.io/badge/Flask-70747C?style=flat&logo=flask&logoColor=white)

### 🌫️ [Stable Diffusion from Scratch](https://github.com/abhayKashyap03/stable_diffusion)

**From noise to images, with the machinery exposed.** A modular PyTorch latent diffusion pipeline with a custom DDPM implementation, UNet, and CLIP. An exercise in understanding the model by implementing its parts.

![Python](https://img.shields.io/badge/Python-587D91?style=flat&logo=python&logoColor=white) ![PyTorch](https://img.shields.io/badge/PyTorch-A76954?style=flat&logo=pytorch&logoColor=white)
